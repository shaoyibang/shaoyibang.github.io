# 邵乙梆（Sean）的个人站

一个零构建、零依赖的静态个人网站，内容分成三个模块：**随笔 / 工具 / 作品**（首页从上到下也是这个顺序）。
**首页是手绘插画版「小街区」**，另外保留了一版 Bento 网格设计作为备选：

| 页面 | 风格 | 说明 |
| --- | --- | --- |
| `index.html` | **手绘插画「小街区」** | 整屏手绘 SVG 街景 + 编号菜单 + 四套配色，全站内页统一这个风格 |
| `bento.html` | **Bento 网格**（备选） | Apple / Linear 气质，12 列模块化卡片。只是个孤立的备选首页，内页链接指向插画版 |

直接双击 `index.html` 就能看，不需要 `npm install`，也不需要任何服务器。

## 立刻看效果

```powershell
# 方式一：直接打开
start index.html

# 方式二：起一个本地服务（推荐，路径与相对链接的行为和线上一致）
npx --yes serve . -l 4321
# 然后访问 http://localhost:4321
```

## 四套配色

右上角的四个圆点，或内页顶栏同样的四个圆点，都可以切换。选择会写进 `localStorage`，全站跟随。

| 名称 | `data-palette` | 感觉 |
| --- | --- | --- |
| 白天 | `day` | 参考图的原始配色：淡蓝天空 + 黄太阳 + 粉/奶油/青绿/绿的街景 |
| 黄昏 | `dusk` | 紫→桃的渐变天空、橙色落日、暖调建筑，星星开始出现 |
| 夜晚 | `night` | 深蓝夜空 + 月亮 + 星星，**窗户和招牌全部亮起来**（`--win` 变成暖黄） |
| 复古印刷 | `print` | 米黄纸底 + 红/芥末黄/墨绿限定色，叠了一层半调网点 |

实现方式：全部颜色都是 CSS 变量，**同一套 SVG 一行不改**，换 `[data-palette]` 就整体换色。
新增一套配色只要在 `illustrated.css` 里加一个 `[data-palette="xxx"] { ... }` 块。

## 首页怎么改

| 想改什么 | 改哪里 |
| --- | --- |
| 街道上的建筑、公交、海浪、云、星星 | `index.html` 里那一整块 `<svg>`，按注释分组 |
| 可点击的建筑 | SVG 里带 `data-goto="#works"` 的 `<g class="hotspot">`，同时改 `data-label` / `data-sub`（招牌文案） |
| 招牌气泡 | `illustrated.css` 的 `.sign`，`illustrated.js` 的 `showSign()` |
| 公交行驶速度 | `illustrated.css` 的 `@keyframes drive` 与 `.drive`（负 `animation-delay` 让它一进页面就在街上） |
| 菜单项 | `.menu__list` 里的 `li`，顺序号 / 中文名 / 英文名三处一起改 |
| 标题字体 | `ZCOOL KuaiLe`（中文）+ `Baloo 2`（拉丁），在 `<head>` 的 Google Fonts 链接里 |
| 窄屏场景构图 | `assets/js/illustrated.js` 末尾的 `fitScene()`：宽屏用 `slice` 铺满，窄屏切到 `meet` 让整条街贴底显示 |
| 首页区块的顺序 | `<main>` 里四段 `<!-- ===== 区块名 ===== -->` 注释。**只有「作品」是青色色带**，它前后各有一条 `.wave-div` 波浪，搬这个区块必须把两条波浪一起搬，否则色带边缘会露出生硬的直角 |
| 左上角那枚北京时间 | HTML 是顶栏里的 `<time class="clock">`，逻辑在 `illustrated.js` 末尾的 `clock()`（时区写死 UTC+8），外观在 `illustrated.css` 的 `.clock` |
| 节假日倒计时 | `illustrated.js` 末尾 `countdown()` 里的 `HOLIDAYS` 表，一行一个 `["2027-02-05", "春节"]`。**表里填的是"放假首日"，春节按除夕算**；官方调休安排每年年底才公布（2027 年那份目前还没出），公布后照公告改对应的行即可。表用完会自动退回"明年元旦"，不会空着 |
| 浏览器标签页图标 | 每个 HTML `<head>` 里的 `rel="icon"`，是一段 URL 编码的 SVG data URI，改字母时只动 `%3E…%3C` 之间的内容 |
| 背景音乐换一首 | 把新文件放到根目录并在 7 个页面的 `<audio id="bgm" src=…>` 里改文件名（`blog/` 下要写 `../`）；想让它不循环就删掉 `loop` |
| 音乐开关长什么样 | `illustrated.css` 的 `.music` / `.music.is-on`；联动逻辑（含跨页续播）在 `illustrated.js` 末尾的 `bgm()`，音量就是里面那个 `VOLUME = 0.85` |

内页（随笔 / 工具 / 作品）不用改结构，只共用同一个顶栏外壳：`.ih` + `.ih__nav` + `.palette` + `.clock`。
新增内页时把这几段照抄、改 `is-active` 和相对路径（`blog/` 下记得加 `../`）即可。

## 踩过的坑（都修好了，改的时候别改回去）

1. **CSS `transform` 会覆盖 SVG 的 `transform` 属性**。带 `animation: float/bob/drive/drift` 的元素必须
   外层套一个负责定位的 `<g transform="...">`，动画只加在内层 `<g>` 上，否则图形会塌到原点。
   公交的「定位 / 行驶 / 颠簸」就是三层 `<g>` 各管一件事。
2. **不要给 `aria-hidden` 的装饰 SVG 里放 `tabindex` 元素**。街景整块是装饰性的，
   建筑只是鼠标用户的快捷入口；键盘和读屏用户走菜单，那条路径是完整的。
3. **`animation-delay` 用负值**：公交的循环有 58 秒，不加负延迟的话用户进页面要等十几秒才看到车。
4. **算北京时间别掺 `getTimezoneOffset()`**。时间戳本身是绝对时间，`new Date(Date.now() + 8 * 3600000)` 之后用 `getUTC*` 读就是北京墙上时间；
   再减一次本机偏移会得到 UTC（本机正好在 UTC+8 时看着还挺像对的，其实是差了 8 小时的假象）。
   这个 bug 只在"本机时区恰好等于 UTC+8"时才装得像对的，改完记得拿 `Get-Date` 对一眼。

## Bento 版（`bento.html`）怎么改

| 想改什么 | 改哪里 |
| --- | --- |
| 名字、标语、自我介绍 | `bento.html` 里 `.tile--hero` 区块 |
| 导航项 | `.nav__links` 与移动端 `.tabbar`（两处要同步） |
| 随机语录 | `assets/js/main.js` 里的 `QUOTES` 数组 |
| 配色 / 圆角 / 间距 / 字体 | `assets/css/style.css` 顶部的 `:root` 与 `[data-theme="dark"]` |

改主题只动两个地方就够了：浅色变量在 `:root`，深色覆盖在 `[data-theme="dark"]`。所有组件都只引用变量，没有硬编码颜色。

## 已经内置的东西

- **整屏手绘 SVG 街景**：4 栋建筑 + 公交 + 小船 + 海浪 + 云 + 星星 + 角色，全部是代码画的，没有引用任何图片素材。
- **四套配色**：白天 / 黄昏 / 夜晚 / 复古印刷，全站跟随且持久化。
- **会动**：三层海浪视差漂移、云朵浮动、**公交沿街开来开去**、船与车身轻微起伏、尾气噗噗冒。
- **彩蛋**：点街上的任何一栋楼，它会"咚"地弹一下、冒出一块写着栏目名的招牌气泡，然后带你滚到对应区块。
- **编号菜单**：右上角按钮或按 `M` 打开，01–06 编号项 + 圆形箭头，点遮罩 / `Esc` / 关闭按钮任意方式可关。
- **焦点管理**：打开时聚焦第一项，`Tab` 锁在弹窗内，关闭后焦点回到打开它的按钮。
- **三个 Canvas 小工具**：涂鸦板（可导出 PNG）、贪吃蛇（方向键 / WASD / 触屏方向键）、生命游戏（可绘制、单步、环形边界）。画布配色也跟随主题。
- **左上角北京时间**：时间戳直接 `+8h` 再按 UTC 字段读就是北京墙上时间，与访客所在时区无关；每秒走一格，标签页切到后台会停掉定时器，切回来立刻补一次。数字用 `tabular-nums` + 固定宽度，秒跳动时不会左右晃。
- **时钟下面一行倒计时**：`距离中秋节放假还有 1 天`，自动挑下一个法定节假日（元旦 / 春节 / 清明 / 劳动 / 端午 / 中秋 / 国庆），有节假日当天会显示 `今天就是…🎉`。用同一套北京日期算，哪个时区的访客看到的天数都一样；鼠标悬停能看到具体日期。脚本没跑起来时整行是 `hidden`，不会露出空壳。
- **背景音乐开关**：时钟右边那个音符按钮，**默认关闭**，`preload="none"` 意味着不点它就不会下载那 6.8MB。音量固定 **85%**（`illustrated.js` 里的 `VOLUME`），放着的时候按钮变青底黄音符、音符轻轻跳。换页会接着放（位置记在 `sessionStorage`）；浏览器若以自动播放策略拦下，按钮就老实停回"关"的状态，不会出现"亮着但没声音"。
- **站点图标 / 徽章**：`SYB`（favicon 与左上角 logo 徽章同一套字，改的时候两个地方一起改）。
- **响应式场景**：宽屏 `slice` 铺满画面；窄屏自动切到 `meet`，让整条街缩小贴在底部，不会被裁成中间一栋楼。
- **Bento 版附赠**：命令面板（`⌘K`）、深浅双主题、移动端底部标签栏、`IntersectionObserver` 入场动画
  （隐藏态写在 `.js .reveal` 下——脚本挂了或被禁用时内容照样完整可读，不会变成一片空白）。
- **可访问性**：跳转链接、可见焦点环、图标按钮全部有可访问名称、`aria-expanded` / `aria-modal` / `role="dialog"`、
  配色切换是标准 `radiogroup` 且支持方向键、全程尊重 `prefers-reduced-motion`。
- **零外链依赖**：除 Google Fonts 外没有任何第三方请求；字体被墙时会回落到系统字体栈，布局不会跳。

## 设计依据

**首页（插画版）**：手绘卡通风——平涂色块 + 厚描边 + 圆润粗体 + 贴纸感徽章。
字体 ZCOOL KuaiLe（中文标题，自带手写感）+ Baloo 2（拉丁标题，圆钝粗体）+ Nunito（正文）。
所有圆角 18–28px、卡片阴影统一用硬投影（不用模糊阴影），交互反馈是位移而不是缩放，这样厚描边的"实体感"才不会被破坏。
深色配色下的描边与卡片边框分开取色（`--ink` 给 SVG，`--edge` 给 HTML），否则夜里边框会糊在背景里。

**Bento 版**：Bento Grid / Apple-Linear 气质。字体 Space Grotesk（标题）+ Archivo（正文）+ JetBrains Mono（数字与代码）。
网格规则：**桌面 12 列、平板 6 列、手机 1 列**，每行跨度之和必须等于列数，因此不需要 `grid-auto-flow: dense`，键盘 Tab 顺序天然等于视觉顺序。
